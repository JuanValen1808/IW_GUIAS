# Turismo Chillán Digital - SPA con Vue 3

## Parte 1: Análisis de Sistemas
* **Módulos principales:**
  * Inicio: Historia y contexto.
  * Atractivos: Catedral, Termas, Valle Las Trancas, Feria.
  * Gastronomía: Longanizas, Pan Amasado, Vinos del Itata.
  * Contacto: Formulario de consultas.
* **Mapa de navegación:** Estructura centralizada mediante `Navbar` navegable utilizando `Vue Router`.
